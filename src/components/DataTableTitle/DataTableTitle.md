# DataTableTitle

**Import:** `import { DataTableTitle } from "./components/DataTableTitle"`
**Category:** components
**Intent:** Header bar above a DataTable — title with optional subtitle and right-aligned actions slot

## Props

- `children`: ReactNode (required) — Title text.
- `actions`: ReactNode — Optional right-aligned actions (buttons, icons, etc.).
- `subtitle`: ReactNode — Optional subtitle / description below the title.
