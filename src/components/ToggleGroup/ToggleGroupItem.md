# ToggleGroupItem

**Import:** `import { ToggleGroupItem } from "./components/ToggleGroup"`
**Category:** components
**Intent:** Group of Toggle buttons with single- or multiple-selection mode (type), sharing variant/size

## Composition

`ToggleGroupItem` is part of a compound component. Use together with: `ToggleGroup`.

All pieces import from the same path (`./components/ToggleGroup`). See each sibling's `.md` for its API.

## Props

- `value`: string (required)
- `variant`: "default" | "outline"
- `size`: "small" | "medium" | "large" | "sm" | "lg"
