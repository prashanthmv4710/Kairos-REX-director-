# Scrim

**Import:** `import { Scrim } from "./components/Scrim"`
**Category:** components
**Intent:** Backdrop dimming primitive for PX overlays (isOpen/isClosing animation). Modal/Panel already include their own scrim

## Props

- `variant`: "default" | "inverse" — Visual variant of the scrim.
- `isOpen`: boolean — Whether the scrim is visible / open.
- `isClosing`: boolean — Whether the scrim is in a closing animation state.
