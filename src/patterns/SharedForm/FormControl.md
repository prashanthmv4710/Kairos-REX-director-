# FormControl

**Import:** `import { FormControl } from "./patterns/SharedForm"`
**Category:** patterns

## Composition

`FormControl` is part of a compound component. Use together with: `Form`, `FormField`, `FormItem`, `SharedFormLabel`, `FormDescription`, `FormMessage`.

All pieces import from the same path (`./patterns/SharedForm`). See each sibling's `.md` for its API.
